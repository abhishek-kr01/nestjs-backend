# NestJS Backend

A hands-on backend codebase covering core and advanced NestJS concepts, patterns, and backend development practices.

## Topics Covered

* NestJS project structure
* Modules, Controllers & Services
* Environment Configuration
* RESTful APIs & CRUD
* DTOs, Pipes & Validation
* PostgreSQL & TypeORM
* Authentication with JWT & bcrypt
* JWT Strategies & Auth Guards
* Role-Based Access Control (RBAC)
* Rate Limiting & Security
* Caching
* Pagination & Filtering
* File Uploads
* Events & Listeners
* Interceptors
* Middleware

## Tech Stack

* NestJS
* TypeScript
* PostgreSQL
* TypeORM
* JWT
* bcrypt

## Purpose

This repository contains practical implementations and reference code for building backend applications with NestJS.
